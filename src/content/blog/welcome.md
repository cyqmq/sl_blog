这是通过 **Astro + Cloudflare Pages** 搭建的博客演示文章。

## 为什么选 Astro

- 内容站点默认零 JS，加载飞快
- Markdown 写文章体验好
- 官方 Cloudflare 适配器，部署无烦恼

## 代码示例

```js
console.log('Hello from Cloudflare Edge!');
```
