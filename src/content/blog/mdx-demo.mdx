## 行内与块级公式（KaTeX）

质能方程： $E = mc^2$

高斯积分：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

## 代码高亮（Shiki，随主题切换）

```ts
interface User {
  id: number;
  name: string;
}

function greet(user: User): string {
  return `Hello, ${user.name}!`;
}
```

## MDX 能力

MDX 允许直接写 JSX，例如一个带样式的提示框：

<div style="padding:12px 16px;border-left:3px solid var(--accent);background:var(--accent-soft);border-radius:8px;">
